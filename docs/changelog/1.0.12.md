# CHATUUTTS 1.0.12 更新说明

发布日期：2026-11-02
安装包：CHATUUTTS-Setup-1.0.12.exe（37 MB）

## 概览

这个版本修好了连续发言时顺序错乱的问题，并把默认快捷键从 Ctrl+A/B/C 改成了 Ctrl+Alt+1/2/3，不再和全选、复制冲突。

## 优化与修复

- **按发送顺序播放**：以前连续发几句话时，短句或有缓存的句子可能抢先播。现在合成仍并行进行，但播放严格按发送顺序。
- **发送时定下声音**：句子还在合成时切换声音档案，这句仍用发送那一刻的声音。
- **连续发言更快**：在线合成复用同一个网络连接，不再每句重新握手。
- **缓存更安全**：音频先写临时文件再改名，程序中途退出不会留下半截文件；空文件不再被当成缓存。
- **空白内容不发送**：词语替换后变成空白的文字会直接跳过。
- **默认快捷键改为 Ctrl+Alt+1/2/3**：旧的 Ctrl+A/B/C 一开启全局快捷键就会占掉全选和复制。只影响新安装，已有的快捷键设置不变。
