# CHATUUTTS 1.0.13 更新说明

发布日期：2026-11-02
安装包：CHATUUTTS-Setup-1.0.13.exe（173 MB）

## 概览

从这个版本开始，CHATUUTTS 可以完全离线说话：新增 8 个本地音色，合成在本机完成，不再依赖网络。在线音色（Xiaomo 等）保持不变，两种可以随时切换。

## 新功能：本地离线语音

**怎么用**

1. 打开「编辑配置」或「新建配置」。
2. 在音色列表最后选「本地 女1–4」或「本地 男1–4」（标注「离线 · 女声/男声」）。
3. 点「试听」确认效果，再点「保存」。之后发言、快捷键和虚拟麦克风都走本地合成。

**速度（本机实测）**

| 场景 | 耗时 |
| --- | --- |
| 首次加载模型（启动时在后台完成） | 约 1.5 秒 |
| 短句，如「你好」「打一把cod吧」 | 0.5–1.4 秒 |
| 约 6 秒长的一句话 | 约 4 秒 |
| 同一句话第二次（读缓存） | 几乎即时 |

**可调参数**：本地音色只有语速和音量生效。固定搭配和词语替换（如 cod → C O D）照常生效。

**模型**：Kokoro v1.1 中文增强版（int8），由 sherpa-onnx 在 CPU 上运行，已内置在安装包里，无需单独下载，Apache-2.0 许可。

## 安装与升级

直接运行 CHATUUTTS-Setup-1.0.13.exe 覆盖安装即可，原有的配置和声音档案都会保留。

- 安装位置不变：`%LOCALAPPDATA%\CHATUUTTS`，不需要管理员权限。
- 已有的 config 文件不会被覆盖，包括声音档案、快捷键、词语替换和界面状态。
- 安装后占用约 346 MB（其中本地模型约 206 MB）。
- 仍需先装好 VB-CABLE 驱动，安装包不附带驱动。
- 安装目录里附带 README.md、全部更新说明（docs\changelog）、LICENSE.txt 和第三方声明 THIRD_PARTY_NOTICES.md。

## 已知限制

- 本地音色不支持风格、角色、音调和风格强度，编辑器里这些选项暂时仍会显示，调了不起作用。
- 本地音质比在线的 Azure 音色自然度稍差，需要带情绪的语气时建议切回在线音色。
- 长句在 CPU 上合成需要几秒，会比在线稍慢。
- 8 个本地音色是从模型 100 个中文说话人里均匀挑选的，之后可以按试听反馈更换。
- 在线合成的接口密钥仍以明文随安装包分发，这一点本次未改。
