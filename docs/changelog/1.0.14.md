# CHATUUTTS 1.0.14 更新说明

发布日期：2026-11-05
安装包：CHATUUTTS-Setup-1.0.14.exe（约 173 MB）

## 概览

从这个版本开始，CHATUUTTS 可以自己检查更新、在程序里一键更新，不用再手动去下载安装包。

## 新功能：更新提示与程序内更新

- **启动时检查更新**：程序启动几秒后在后台检查一次 GitHub 上的最新版本。没联网或检查失败时不打扰你。
- **更新提示**：有新版本时会弹出提示，显示这次的更新说明。展开模式下工具栏还会多一个「更新到 x.x.x」按钮。
- **一键更新**：点「立即更新」后，程序会下载安装包并显示进度，校验无误后自动安装，装完自动重新打开。配置和声音档案都会保留。
- **可以跳过**：选「跳过这个版本」后，这个版本不再自动提示；有更新的版本时会再提示。
- **右键菜单**：新增「检查更新」「启动时检查更新」开关和当前版本号。关掉自动检查后，程序启动时不会联网。

**安全**：安装包下载后会和 Release 里的 SHA-256 校验值比对，对不上就不会安装。

## 安装与升级

- 1.0.13 及更早的版本没有更新功能，需要手动安装一次 1.0.14。之后的版本就能在程序里直接更新了。
- 覆盖安装即可，原有的配置和声音档案都会保留。
- 程序内更新用的是静默安装，不会再提示 VB-CABLE 检查。

## 已知限制

- 每次更新都会下载完整的安装包（约 173 MB）。
- 从源码运行时不会自动安装更新，「立即更新」会改为打开下载页。
- 程序内更新的完整流程（从 1.0.14 更新到下一个版本）要等下一个版本发布后才能实际验证；静默安装、运行中覆盖和自动重新打开已经在本机用测试安装包验证过。

## 开发者附录

| 文件 | 改动 |
| --- | --- |
| lib/version.py | 新增：程序版本号和仓库名，发版时和 iss 一起改 |
| lib/updater.py | 新增：检查最新版本、下载、SHA-256 校验、静默启动安装包。不调用 api.github.com，避免每小时 60 次的未登录限额 |
| lib/mainWindow.py | 更新弹窗、工具栏按钮、右键菜单项 |

**发版要求**：每个 Release 的标签必须是 `v<版本号>`，附件里要有 `CHATUUTTS-Setup-<版本号>.exe` 和同名的 `.sha256` 文件；仓库里对应标签下要有 `docs/changelog/<版本号>.md`。程序靠这三样找到新版本、校验安装包并显示更新说明。
